# 回帰

**連続値を予測する。** 統計側の[[数学/統計/回帰|回帰]]と同じ枠組み。

## 線形回帰

$$\hat{y} = w^\top x + b$$

二乗誤差を最小化すると、[[数学/線形代数/射影|正規方程式]]で解ける。

$$\hat{w} = (X^\top X)^{-1}X^\top y$$

**閉じた形の解がある**のが線形回帰の大きな利点。
反復も学習率の調整も要らない。

## 二乗誤差の根拠

誤差が正規分布に従うと仮定したときの最尤推定。

$$y = w^\top x + \varepsilon, \quad \varepsilon \sim \mathcal{N}(0,\sigma^2)
\;\Longrightarrow\; \arg\max \log L = \arg\min \sum (y_i - w^\top x_i)^2$$

外れ値に弱いのは、二乗が大きな誤差を強く罰するため。
頑健にしたければ Huber 損失などを使う。

## 正則化

| 手法 | 罰則 | 効果 |
| --- | --- | --- |
| Ridge | $\lambda\|w\|_2^2$ | 係数を小さく。[[数学/数値計算/条件数\|条件数]]を改善 |
| Lasso | $\lambda\|w\|_1$ | 係数が**0 になる**。変数選択 |
| Elastic Net | 両方 | 相関する変数群をまとめて扱う |

$L_1$ で 0 になるのは、
[[数学/線形代数/ノルム|$L_1$ 球が座標軸上に尖った頂点を持つ]]ため。

## 非線形化

特徴量を非線形変換すれば、線形回帰のまま非線形な関係を扱える。
カーネル法、多項式回帰、そして
[[人工知能/ニューラルネットワーク|ニューラルネットワーク]]は
この延長線上にある。
