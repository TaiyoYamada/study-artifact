# 量子化学の基礎

## 出発点

分子のハミルトニアンは、核と電子のすべての相互作用を含む。

$$H = T_e + T_n + V_{ee} + V_{nn} + V_{en}$$

このままでは扱えないので、順に近似していく。

## 近似の順序

1. **[[量子化学/ボルン・オッペンハイマー近似|Born-Oppenheimer 近似]]**
   — 核を止めて電子だけを解く
2. **基底関数への展開** — 無限次元を有限次元にする
3. **[[量子化学/ハートリー・フォック法|Hartree-Fock]]** — 電子間反発を平均場で近似
4. **[[量子化学/電子相関|電子相関]]の取り込み** — HF の誤差を補正

## 化学的精度

$$1\ \text{kcal/mol} \approx 1.6 \times 10^{-3}\ \text{Hartree}$$

反応速度を実験と比べられる水準がこの精度。
**全エネルギーの $10^{-4}$ 程度の相対精度**が要る。

厳しいのは、全エネルギーが数百 Hartree なのに対し、
化学的に意味を持つ差は $10^{-3}$ Hartree であること。
**大きな数の差を精密に求める**必要がある。
[[最適化/量子最適化/VQEによる最適化|VQE]] の測定回数が
膨大になる根本的な理由もここにある。

## 基底関数

原子軌道を数学的な関数で近似したもの。
STO-3G（最小基底）から cc-pVQZ（高精度）まで階層がある。

基底関数が増えると精度は上がるが、
**軌道数 = 必要な量子ビット数**なので、
量子計算では基底の選択が資源に直結する。
