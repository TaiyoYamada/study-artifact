# 量子チャネル

**量子状態から量子状態への、物理的に許される変換すべて。**
完全正値トレース保存写像 (CPTP map)。

$$\mathcal{E}: \rho \mapsto \mathcal{E}(\rho)$$

## ユニタリより広い

| 操作 | チャネルか |
| --- | --- |
| [[数学/量子計算のための数学/ユニタリ行列\|ユニタリ]]変換 | はい（可逆な場合） |
| ノイズ | はい |
| [[量子情報/量子測定\|測定]]（結果を捨てる） | はい |
| 補助系の追加・破棄 | はい |

閉じた系ならユニタリで足りるが、
**環境と相互作用する開いた系**を扱うにはチャネルが要る。

## Kraus 表現

任意のチャネルは次の形に書ける。

$$\mathcal{E}(\rho) = \sum_k K_k \rho K_k^\dagger, \qquad \sum_k K_k^\dagger K_k = I$$

$K_k$ が Kraus 演算子。この形で書けることが
**物理的に実現可能**であることと同値。

## 代表的なノイズチャネル

| チャネル | 作用 |
| --- | --- |
| ビット反転 | 確率 $p$ で $X$ を作用 |
| 位相反転 | 確率 $p$ で $Z$ を作用 |
| 脱分極 | 確率 $p$ で最大混合状態に置き換える |
| 振幅減衰 | $\|1\rangle \to \|0\rangle$。エネルギー緩和（$T_1$） |
| 位相緩和 | 非対角成分の減衰（$T_2$） |

実機のノイズはこれらの組み合わせでモデル化される。
[[量子誤り訂正/量子誤りとは何か|量子誤り訂正]]は、
これらの効果を打ち消す仕組み。

## Stinespring 表現

任意のチャネルは、**より大きな系でのユニタリ変換 + 部分トレース**として実現できる。

$$\mathcal{E}(\rho) = \mathrm{Tr}_E\bigl(U(\rho \otimes |0\rangle\langle 0|_E)U^\dagger\bigr)$$

**ノイズとは、環境ともつれて環境を見失うこと**という描像を与える。
