# ブロッホ球

1 [[量子コンピューティング/量子ビット|量子ビット]]の状態を、
**3 次元の球面上の点**として表す図。

$$|\psi\rangle = \cos\frac{\theta}{2}|0\rangle + e^{i\phi}\sin\frac{\theta}{2}|1\rangle$$

$(\theta, \phi)$ が球面の極座標。

## 主な点

| 位置 | 状態 |
| --- | --- |
| 北極 | $\|0\rangle$ |
| 南極 | $\|1\rangle$ |
| $x$ 軸上 | $\|\pm\rangle = (\|0\rangle \pm \|1\rangle)/\sqrt2$ |
| $y$ 軸上 | $(\|0\rangle \pm i\|1\rangle)/\sqrt2$ |

**直交する状態が対蹠点**（$|0\rangle$ と $|1\rangle$ が北極と南極）になる点が
ヒルベルト空間の直交と食い違うので注意。
角度が半分になっているため。

## ゲート = 回転

[[量子コンピューティング/量子ゲート|1 量子ビットゲート]]は、
すべてブロッホ球上の**回転**として表せる。

| ゲート | 回転 |
| --- | --- |
| $X$ | $x$ 軸まわり $180°$ |
| $Z$ | $z$ 軸まわり $180°$ |
| $H$ | $(x+z)/\sqrt2$ 軸まわり $180°$ |
| $R_z(\theta)$ | $z$ 軸まわり $\theta$ |

回転なので長さが保たれ、常に球面上に留まる。
これが[[数学/量子計算のための数学/ユニタリ行列|ユニタリ性]]の幾何的な意味。

## 内部は混合状態

球の**表面**が純粋状態、**内部**が[[量子情報/純粋状態と混合状態|混合状態]]、
**中心**が最大混合状態。

$$\rho = \frac{1}{2}(I + \vec r \cdot \vec\sigma), \qquad |\vec r| \le 1$$

[[量子情報/デコヒーレンス|デコヒーレンス]]は
**点を中心へ引き寄せる**操作として描ける。
ノイズの効果を視覚化する標準的な道具。

## 2 量子ビット以上には使えない

ブロッホ球が使えるのは 1 量子ビットまで。
$n$ 量子ビットの状態空間は $2^{n+1}-2$ 実次元で、
[[量子力学/量子もつれ|もつれ]]を含む構造は 3 次元では描けない。
