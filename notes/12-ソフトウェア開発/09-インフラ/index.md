# インフラ

**書いたものを動かし続ける場所と仕組み。**

## 関心事

| 関心事 | 問い |
| --- | --- |
| 再現性 | 同じものが同じように動くか |
| 可用性 | 落ちないか、落ちても戻るか |
| 拡張性 | 負荷が増えたら増やせるか |
| 観測性 | 何が起きているか分かるか |
| 費用 | いくらかかるか |
| 安全性 | 侵入されないか |

## 変化の方向

```
物理サーバ → 仮想マシン → [[コンテナ]] → [[サーバーレス]]
（買う）    （借りる）   （軽く分ける） （実行だけ買う）
```

**抽象度が上がり、管理する対象が減っていく**方向。
代わりに制御できる範囲も減り、
プラットフォームへの依存が増える。
