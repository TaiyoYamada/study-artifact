# データベース

**データを永続化し、効率よく問い合わせられるようにする**システム。

## ファイルとの違い

ファイルでも保存はできる。DB が提供するのは

| 機能 | 内容 |
| --- | --- |
| **問い合わせ** | 条件で絞る、結合する、集計する |
| **[[ソフトウェア開発/データベース/インデックス\|索引]]** | 全件走査せずに見つける |
| **[[ソフトウェア開発/データベース/トランザクション\|トランザクション]]** | 途中で落ちても壊れない |
| 並行制御 | 同時アクセスの整合 |
| 制約 | 不正なデータを拒否する |
| 復旧 | 障害からの回復 |

**「壊れない」ことが最も価値がある。**
問い合わせは自分でも書けるが、
障害時の整合性を自前で保証するのは非常に難しい。
