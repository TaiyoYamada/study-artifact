# 研究

**まだ分かっていないことを、確かめられる形で明らかにする。**

## 流れ

```
[[論文の読み方]]・[[先行研究調査]]    何が分かっていて、何が分かっていないか
        ↓
[[研究課題の立て方]]・[[仮説]]        何を問うか
        ↓
[[実験設計]]・[[ベースライン]]        どう確かめるか
        ↓
[[アブレーション]]・[[評価指標]]      何が効いているのか
        ↓
[[統計的検定]]・[[再現実験]]          その差は本物か
        ↓
[[研究発表]]・[[論文執筆]]            どう伝えるか
```

## 中心にある態度

**「自分の主張が間違っている可能性を、自分で潰す」**こと。

- 良い結果が出たら、まず**別の説明**を探す
- 都合の良い条件だけで測っていないか疑う
- [[研究/ベースライン|比較対象]]を有利に扱わなかったか確かめる

査読者や読者に指摘される前に、
自分で最も厳しい批判者になる。
