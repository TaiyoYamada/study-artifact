# プログラミング言語

人間が書いたテキストが、どうやって意味を持つのか。

## 3 つの層

| 層 | 問い | 担当 |
| --- | --- | --- |
| **字句** | どこが単語の切れ目か | [[コンピュータ/プログラミング言語/字句解析\|字句解析]] |
| **構文** | どういう構造か | [[コンピュータ/プログラミング言語/構文解析\|構文解析]] |
| **意味** | 何を表しているか | [[コンピュータ/プログラミング言語/意味解析\|意味解析]]、[[コンピュータ/プログラミング言語/型システム\|型システム]] |

自然言語の音韻論・統語論・意味論に対応する。

```
x = 1 + 2 * 3
   ↓ 字句解析
[x] [=] [1] [+] [2] [*] [3]
   ↓ 構文解析
     =
    /    x    +
       /       1   *
         /         2   3
   ↓ 意味解析
型は？ 変数 x は宣言されている？
```

## 形式言語との対応

| 文法 | 認識する機械 | 用途 |
| --- | --- | --- |
| 正規文法 | 有限オートマトン | [[コンピュータ/プログラミング言語/字句解析\|字句解析]] |
| 文脈自由文法 | プッシュダウンオートマトン | [[コンピュータ/プログラミング言語/構文解析\|構文解析]] |
| 文脈依存 | — | 型検査などは通常の手続きで行う |

**括弧の対応**は正規言語では表現できない（反復補題）ので、
字句と構文を分ける必要がある。
この階層は理論的な必然であって、便宜ではない。
