# メモリ

プログラムとデータを置く主記憶。DRAM。

## DRAM と SRAM

| | DRAM（主記憶） | SRAM（[[コンピュータ/コンピュータアーキテクチャ/キャッシュ\|キャッシュ]]） |
| --- | --- | --- |
| 1 bit の構成 | トランジスタ 1 + コンデンサ 1 | トランジスタ 6 |
| 密度 | 高い（安い） | 低い（高い） |
| 速度 | 遅い | 速い |
| リフレッシュ | **必要**（電荷が漏れる） | 不要 |

DRAM は電荷を蓄えて記憶するので、
数ミリ秒ごとに読み直して書き戻す必要がある。
この間はアクセスできない。

## メモリの壁

CPU の性能は年 50% 以上向上した時期があったが、
DRAM のレイテンシは年 7% 程度しか改善しなかった。
**差が指数的に開いた**のがメモリの壁。

帯域は改善している（DDR、HBM）が、
**レイテンシは物理的な制約でほとんど改善しない**。
そのため

- キャッシュ階層を深くする
- プリフェッチで先読みする
- 多数のスレッドで待ち時間を隠す（GPU の方式）

といった「隠す」対策が中心になる。

## アドレス空間

プロセスが見るアドレスは[[コンピュータ/オペレーティングシステム/仮想メモリ|仮想アドレス]]で、
MMU が物理アドレスに変換する。

```
高位 ┌──────────┐
     │ スタック  │ ↓ 伸びる
     │          │
     │ ヒープ    │ ↑ 伸びる
     │ データ    │ 静的変数
     │ テキスト  │ 機械語
低位 └──────────┘
```
