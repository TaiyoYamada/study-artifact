# コンピュータアーキテクチャ

**ハードウェアとソフトウェアの境界の設計。**

## フォン・ノイマン型

現代のコンピュータのほぼすべてがこの構成。

```
   [[CPU]] ←→ [[メモリ]] ←→ 入出力
    ↑
  [[キャッシュ]]
```

**命令もデータも同じメモリに置く**のが特徴。
プログラムをデータとして扱えるので、
[[コンピュータ/言語処理系/コンパイラ|コンパイラ]]や
[[コンピュータ/言語処理系/JITコンパイル|JIT]] が成立する。

同時に、CPU とメモリの間の帯域が全体の律速になる
（**フォン・ノイマン・ボトルネック**）。
[[コンピュータ/コンピュータアーキテクチャ/キャッシュ|キャッシュ]]、
[[コンピュータ/コンピュータアーキテクチャ/パイプライン|パイプライン]]、
[[コンピュータ/コンピュータアーキテクチャ/GPU|GPU]] はいずれも
この制約への対処と見ることができる。

## 性能の式

$$\text{実行時間} = \text{命令数} \times \text{CPI} \times \text{クロック周期}$$

3 つの因子のどれを改善するかで手法が分かれる。

| 因子 | 改善手段 |
| --- | --- |
| 命令数 | 命令セット設計、コンパイラ最適化 |
| CPI | パイプライン、スーパースカラ、キャッシュ |
| クロック周期 | 微細化（近年は頭打ち） |

クロックの向上が 2000 年代に電力の壁で止まったため、
**並列化が唯一の残された道**になった。
