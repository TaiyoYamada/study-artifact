# 焼きなまし・局所探索

**現在の解を少しずつ変えながら良くしていく**手法群。
[[最適化/導関数を使わない最適化/局所探索|局所探索]]を土台に、
局所最適解から抜け出す仕掛けを足したもの。

## 抜け出し方の違い

| 手法 | 抜け出す仕掛け |
| --- | --- |
| [[最適化/焼きなまし・局所探索/焼きなまし法\|焼きなまし法]] | 悪化も確率的に受け入れる。確率は温度で制御 |
| [[最適化/焼きなまし・局所探索/タブー探索\|タブー探索]] | 直前の手を禁じ、来た道を戻れなくする |
| 反復局所探索 | 局所解に落ちたら大きく揺さぶって再開 |

集団を持たないので**記憶量が小さく実装が短い**のが利点。
[[最適化/組合せ最適化|組合せ最適化]]で特に使われる。
