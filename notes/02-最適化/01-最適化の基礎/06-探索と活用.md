# 探索と活用

**活用 (exploitation)** は今わかっている良い場所を深掘りすること。
**探索 (exploration)** はまだ見ていない場所を調べること。
限られた評価回数をこの 2 つにどう配分するかが、非凸問題での性能を決める。

## なぜ両立しないのか

評価回数は有限なので、片方に使えばもう片方には使えない。

- 活用に偏る → 最初に見つけた谷を掘り続け、局所最適解で終わる
- 探索に偏る → 広く浅く見るだけで、どこも十分に詰められない

## 各手法がどう配分しているか

| 手法 | 配分の仕組み |
| --- | --- |
| [[最適化/焼きなまし・局所探索/焼きなまし法\|焼きなまし法]] | 温度。高温では悪化も受け入れ（探索）、下げるにつれ活用へ |
| [[最適化/進化計算/CMA-ES\|CMA-ES]] | 探索分布の広がり。ステップサイズ $\sigma$ が縮むと活用に寄る |
| [[最適化/群知能/PSO\|PSO]] | 個体の最良と群れの最良、どちらに強く引かれるかの係数 |
| [[最適化/導関数を使わない最適化/ベイズ最適化\|ベイズ最適化]] | 獲得関数。予測値（活用）と不確かさ（探索）を明示的に足す |
| [[最適化/群知能/ABC\|ABC]] | Scout Bee。停滞した解を捨てて無作為に打ち直す |

強化学習の多腕バンディット問題でも同じ構図が現れ、そちらでは
$\varepsilon$-greedy や UCB として定式化されている。
