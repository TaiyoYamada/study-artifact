# 丸め誤差

実数を[[数学/数値計算/浮動小数点|浮動小数点]]で表すときに生じる誤差。

$$\mathrm{fl}(x) = x(1 + \delta), \qquad |\delta| \le \varepsilon$$

1 回の演算では**相対誤差が機械イプシロン以下**に収まる。
問題は、それが積み重なったときの振る舞い。

## 蓄積の仕方

$n$ 回の演算で誤差が $\mathcal{O}(n\varepsilon)$ になるとは限らない。

- **良い場合** … 誤差が打ち消し合い $\mathcal{O}(\sqrt{n}\varepsilon)$ 程度
- **悪い場合** … [[数学/数値計算/桁落ち|桁落ち]]で一気に精度を失う

## 総和での対策

素朴な総和は誤差が蓄積する。**Kahan の補正総和**は、
失われた下位ビットを別変数に保持して足し戻す。

$$\text{誤差} : \mathcal{O}(n\varepsilon) \;\to\; \mathcal{O}(\varepsilon)$$

NumPy の `sum` が対分割（pairwise summation）を使っているのも同じ動機で、
$\mathcal{O}(\log n \cdot \varepsilon)$ に抑えている。

## 実務での現れ方

- [[最適化/進化計算/CMA-ES/固有値分解と白色化|共分散行列]]の対称性が崩れる
  → 明示的に $(C + C^\top)/2$ とする
- 確率の積がアンダーフローする
  → [[数学/確率/確率密度関数|対数を取る]]
- 反復計算が収束しない
  → 収束判定に絶対誤差ではなく相対誤差を使う
