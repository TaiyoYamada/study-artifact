# 量子計算のための数学

量子計算を読むために必要な数学。
中心は**複素ベクトル空間の線形代数**で、
[[数学/線形代数|実数の線形代数]]を複素数に拡げたもの。

## 実数からの拡張の対応

| 実数の世界 | 複素数の世界 |
| --- | --- |
| 転置 $A^\top$ | [[数学/量子計算のための数学/エルミート行列\|エルミート共役]] $A^\dagger$ |
| [[数学/線形代数/対称行列\|対称行列]] | [[数学/量子計算のための数学/エルミート行列\|エルミート行列]] |
| [[数学/線形代数/直交行列\|直交行列]] | [[数学/量子計算のための数学/ユニタリ行列\|ユニタリ行列]] |
| $\sum x_i y_i$ | $\sum \overline{x_i} y_i$ |

**構造はほぼ同じで、共役が入るだけ。**

## 量子計算に固有の道具

- [[数学/量子計算のための数学/テンソル積|テンソル積]] — 複数量子ビットの合成。次元が指数的に増える源
- [[数学/量子計算のための数学/Dirac記法|Dirac記法]] — この分野の標準的な書き方
- [[数学/量子計算のための数学/確率振幅|確率振幅]] — 測定確率との関係
