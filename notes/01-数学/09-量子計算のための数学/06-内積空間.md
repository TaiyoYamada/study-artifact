# 内積空間

[[数学/線形代数/内積|内積]]が定義されたベクトル空間。
完備なものを**ヒルベルト空間**と呼び、量子力学の舞台になる。

## 複素内積の条件

$$\langle\phi|\psi\rangle = \overline{\langle\psi|\phi\rangle}$$

$$\langle\psi|\psi\rangle \ge 0, \qquad \langle\psi|\psi\rangle = 0 \iff |\psi\rangle = 0$$

第 1 の条件（共役対称性）により、$\langle\psi|\psi\rangle$ が実数になる。

物理の流儀では**第 1 引数に対して共役線形**、
数学の流儀ではその逆であることが多い。
文献を読むときに確認が要る点。

## 量子力学での意味

| 式 | 意味 |
| --- | --- |
| $\langle\psi\|\psi\rangle = 1$ | 規格化。確率の総和が 1 |
| $\|\langle\phi\|\psi\rangle\|^2$ | $\|\psi\rangle$ を測って $\|\phi\rangle$ を得る確率 |
| $\langle\phi\|\psi\rangle = 0$ | 直交。完全に区別できる状態 |
| $\langle\psi\|A\|\psi\rangle$ | 観測量 $A$ の期待値 |

最後の形が [[最適化/量子最適化/VQEによる最適化|VQE]] の目的関数。

## Cauchy-Schwarz

$$|\langle\phi|\psi\rangle| \le \|\phi\| \, \|\psi\|$$

確率が 1 を超えないことの保証になっている。
不確定性関係の導出でもこの不等式が使われる。
