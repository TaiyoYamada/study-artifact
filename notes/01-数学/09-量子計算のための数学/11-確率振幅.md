# 確率振幅

量子状態を基底で展開したときの**複素係数**。

$$|\psi\rangle = \sum_i c_i |i\rangle, \qquad c_i = \langle i|\psi\rangle \in \mathbb{C}$$

## Born 則

測定して $|i\rangle$ を得る確率は

$$P(i) = |c_i|^2$$

規格化 $\sum_i |c_i|^2 = 1$ が、確率の総和が 1 であることに対応する。

## 振幅と確率の違いが本質

古典確率は非負の実数を足す。振幅は**複素数を足してから絶対値二乗を取る**。

$$\left| c_1 + c_2 \right|^2 = |c_1|^2 + |c_2|^2 + 2\,\mathrm{Re}(\overline{c_1}c_2)$$

最後の**干渉項**が古典には存在しない。
これにより

- 振幅が打ち消し合う（$c_1 = -c_2$ なら確率 0）
- 強め合う

量子アルゴリズムの設計とは、**誤った答えの振幅を打ち消し、
正しい答えの振幅を強める**ことに他ならない。
[[量子アルゴリズム/Groverアルゴリズム|Grover]] の
振幅増幅がその最も分かりやすい例。

## 位相の扱い

| 位相 | 観測可能か |
| --- | --- |
| 大域位相 $e^{i\phi}|\psi\rangle$ | **観測できない**。同じ状態 |
| 相対位相 $c_1$ と $c_2$ の位相差 | **観測できる**。干渉に効く |

$\frac{1}{\sqrt2}(|0\rangle + |1\rangle)$ と
$\frac{1}{\sqrt2}(|0\rangle - |1\rangle)$ は
計算基底で測れば同じ確率分布を与えるが、
アダマール変換してから測れば区別できる。
