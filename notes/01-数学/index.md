# 数学

このノートで扱う数学は、**最適化と量子計算を読むために必要なもの**に絞ってある。
定理の証明よりも、「その概念が何のために導入され、どこで効いてくるか」を書く。

## 分野の並び

| 分野 | 何のために |
| --- | --- |
| [[数学/線形代数\|線形代数]] | ベクトルと行列。量子状態も最適化の探索分布もここに載る |
| [[数学/微分積分\|微分積分]] | 勾配とヘッセ行列。最適化の一階・二階の情報 |
| [[数学/確率\|確率]] | ノイズのある評価、探索分布、量子測定 |
| [[数学/統計\|統計]] | 実験結果をどう主張するか |
| [[数学/離散数学\|離散数学]] | 集合・グラフ・組合せ |
| [[数学/数理論理\|数理論理]] | 命題と証明の骨格 |
| [[数学/数値計算\|数値計算]] | 有限精度で計算するときに何が壊れるか |
| [[数学/最適化のための数学\|最適化のための数学]] | 凸性と最適性条件 |
