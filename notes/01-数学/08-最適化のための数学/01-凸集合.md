# 凸集合

**任意の 2 点を結ぶ線分が、集合の中に収まる**集合。

$$x, y \in C, \; \theta \in [0,1] \;\Longrightarrow\; \theta x + (1-\theta)y \in C$$

「へこみが無い」形。

## 例

| 凸 | 凸でない |
| --- | --- |
| 球、直方体、半空間 | 三日月形、ドーナツ |
| 超平面、[[数学/線形代数/正定値行列\|半正定値行列]]の全体 | 球面（表面だけ） |
| [[最適化/数理最適化/線形計画法\|線形制約]]の実行可能領域 | 整数格子点 |

## 演算で保たれるか

| 演算 | 凸性 |
| --- | --- |
| 積集合 $C_1 \cap C_2$ | **保たれる** |
| 和集合 $C_1 \cup C_2$ | 保たれない |
| アフィン変換 $AC + b$ | 保たれる |

積集合で保たれることが実用上重要。
**複数の凸制約を課しても、実行可能領域は凸のまま**。
だから制約を足しても問題の難易度が跳ね上がらない。

一方、和集合で保たれないことが
「A または B」という条件の扱いにくさに直結する。
論理和の制約は整数変数を要し、
[[最適化/数理最適化/整数計画法|整数計画]]になって NP 困難化する。
