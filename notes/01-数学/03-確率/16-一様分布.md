# 一様分布

$$p(x) = \frac{1}{b-a} \qquad (a \le x \le b)$$

**区間内のどこも等確率。**

## 無情報の表現

「区間内であること以外、何も分からない」を表す分布。
最大エントロピーの原理でも、有界な台のもとでは一様分布が選ばれる。

## 乱数の土台

計算機の疑似乱数は、まず $[0,1)$ の一様乱数を作る。
他の分布はそこから変換して得る。

| 手法 | 内容 |
| --- | --- |
| [[数学/確率/累積分布関数\|逆関数法]] | $F^{-1}(U)$ |
| Box-Muller | 一様 2 つから正規 2 つ |
| 棄却法 | 提案分布から引いて条件で捨てる |

[[科学計算/乱数|疑似乱数生成器]]の品質は、
[[数学/数値計算/モンテカルロ法|モンテカルロ法]]や
確率的最適化の結果に直接影響する。

## 使ってはいけない場面

[[最適化/導関数を使わない最適化/SPSA|SPSA]] の摂動ベクトルには
**一様分布を使えない**。

$$\mathbb{E}\left[\left|\frac{1}{\Delta_{ki}}\right|\right] = \infty$$

0 付近の値を取りうるため、逆モーメントが発散する。
勾配推定の分母に $\Delta_{ki}$ が来るので、
推定値が無限大になる可能性がある。
対称ベルヌーイ（$\pm 1$）なら $|1/\Delta| = 1$ で問題ない。
