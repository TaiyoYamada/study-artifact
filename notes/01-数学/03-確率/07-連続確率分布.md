# 連続確率分布

確率変数が**連続的な値**を取る場合の分布。
[[数学/確率/確率密度関数|確率密度関数]] $p(x)$ で表す。

$$P(a \le X \le b) = \int_a^b p(x)\,dx$$

## 1 点の確率は 0

$P(X = c) = 0$。連続分布では**特定の値ちょうどを取る確率は 0**。
意味を持つのは区間の確率だけ。

だから密度 $p(x)$ は確率ではない。$p(x) > 1$ もありうる。
確率になるのは $p(x)dx$ という形で幅を掛けたとき。

## 代表的な分布

| 分布 | 用途 |
| --- | --- |
| [[数学/確率/一様分布\|一様]] | 無情報。乱数生成の土台 |
| [[数学/確率/正規分布\|正規]] | 誤差、[[数学/確率/中心極限定理\|中心極限定理]]の帰結 |
| [[数学/確率/多変量正規分布\|多変量正規]] | [[最適化/進化計算/CMA-ES\|CMA-ES]] の探索分布 |
| 指数 | 待ち時間 |
| ベータ | 確率そのものの分布。ベイズの共役事前分布 |
