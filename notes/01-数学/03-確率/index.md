# 確率

**不確かさを数として扱う**枠組み。

## この分野で確率が要る理由

| 場面 | 確率が現れる形 |
| --- | --- |
| [[最適化/導関数を使わない最適化/SPSA\|ノイズのある評価]] | 測るたびに値がぶれる |
| [[最適化/ブラックボックス最適化/探索分布\|探索分布]] | 次にどこを調べるかを分布で持つ |
| [[量子力学/測定\|量子測定]] | 結果が本質的に確率的 |
| [[人工知能/機械学習\|機械学習]] | データを確率分布からの標本と見る |

特に量子力学では、確率は「知識の不足」ではなく
**理論に組み込まれた性質**として現れる点が他と違う。
