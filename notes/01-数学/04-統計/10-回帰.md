# 回帰

**説明変数から目的変数を予測する関係式を求める。**

$$y = \beta_0 + \beta_1 x_1 + \cdots + \beta_p x_p + \varepsilon$$

## 最小二乗法

残差二乗和を最小化する。

$$\hat{\beta} = (X^\top X)^{-1} X^\top y$$

これは[[数学/線形代数/射影|射影]]そのもので、
$y$ を $X$ の列空間へ落とした点が予測値。
残差が列空間と直交するという条件から導かれる。

## 多重共線性

説明変数どうしが強く相関すると $X^\top X$ が特異に近づき、
[[数学/数値計算/条件数|条件数]]が悪化する。
係数の推定が不安定になり、符号が反転することさえある。

対処は正則化。リッジ回帰は $\lambda I$ を足して条件数を改善する。

$$\hat{\beta} = (X^\top X + \lambda I)^{-1}X^\top y$$

Lasso（$L_1$ [[数学/線形代数/ノルム|正則化]]）なら係数が 0 になり、
変数選択が同時に行われる。
