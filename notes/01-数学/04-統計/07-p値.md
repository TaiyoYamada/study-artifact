# p値

**帰無仮説が正しいと仮定したとき、観測された結果以上に極端な結果が得られる確率。**

$$p = P(\text{データ以上に極端} \mid H_0)$$

## よくある誤解

| 誤解 | 正しくは |
| --- | --- |
| 帰無仮説が正しい確率 | $P(H_0 \mid D)$ ではなく $P(D \mid H_0)$ |
| 対立仮説が正しい確率 | 何も言っていない |
| 効果の大きさ | 大きさは[[数学/統計/効果量\|効果量]]で測る |
| $p > 0.05$ なら差が無い | 検出できなかっただけ |

$P(D \mid H_0)$ と $P(H_0 \mid D)$ の混同は、
[[数学/確率/ベイズの定理|ベイズの定理]]で見た
条件の向きの取り違えと同じ誤り。

## 試行数を増やせば有意になる

$p$ 値は標本数に依存する。実用上どうでもいい小さな差でも、
$n$ を増やせば $p < 0.05$ になる。

**「統計的に有意」と「実用的に意味がある」は別物。**
だから $p$ 値と一緒に[[数学/統計/効果量|効果量]]と
[[数学/統計/信頼区間|信頼区間]]を報告することが推奨される。

## ASA 声明

米国統計学会は 2016 年に $p$ 値に関する声明を出し、
科学的な結論を $p < 0.05$ だけで下すべきでないこと、
$p$ 値は効果の大きさも結果の重要性も測らないことを明記した。
