# 方向微分

$$D_u f(x) = \lim_{h \to 0} \frac{f(x + hu) - f(x)}{h} = \nabla f(x)^\top u$$

**指定した方向 $u$（単位ベクトル）に沿った変化率。**

## 偏微分の一般化

$u = e_i$ とすれば[[数学/微分積分/偏微分|偏微分]]そのもの。
方向微分は軸方向に限らない、任意の方向についての変化率を与える。

## 勾配との関係

$$D_u f = \|\nabla f\| \cos\theta$$

$\theta$ は $u$ と $\nabla f$ のなす角。

| $\theta$ | 意味 |
| --- | --- |
| 0 | 最も増える。[[数学/微分積分/勾配\|勾配]]方向 |
| $\pi/2$ | 変化しない。等高線に沿う方向 |
| $\pi$ | 最も減る。降下方向 |

## 最適化での使い方

$d$ が**降下方向**であるとは $\nabla f^\top d < 0$ のこと。
勾配降下法は $d = -\nabla f$ を取るが、
$\nabla f^\top d < 0$ を満たせば何でも降下方向になる。

[[最適化/勾配に基づく最適化/Newton法|Newton 法]]の $d = -H^{-1}\nabla f$ が
降下方向であるためには $H$ が[[数学/線形代数/正定値行列|正定値]]である必要があり、
そうでないときに修正が要る理由がここにある。
