# 微分方程式

未知の**関数**とその導関数の関係式。

$$\frac{dy}{dt} = f(t, y)$$

代数方程式が数を求めるのに対し、微分方程式は関数そのものを求める。

## 種類

| 種類 | 特徴 |
| --- | --- |
| 常微分方程式 (ODE) | 独立変数が 1 つ。時間発展など |
| 偏微分方程式 (PDE) | 独立変数が複数。空間と時間 |
| 線形 | 解の重ね合わせが成り立つ |
| 非線形 | 一般に解析解が無い |

## 線形なら行列で解ける

$$\dot{x} = Ax \qquad \Longrightarrow \qquad x(t) = e^{At} x(0)$$

$A$ を[[数学/線形代数/対角化|対角化]]すれば $e^{At} = Pe^{\Lambda t}P^{-1}$ で、
固有値が解の振る舞い（減衰・振動・発散）を決める。

## この分野での登場

**[[量子力学/シュレディンガー方程式|シュレディンガー方程式]]**が最重要。

$$i\hbar \frac{\partial}{\partial t}|\psi\rangle = H|\psi\rangle$$

線形なので上と同じ形で解け、
$|\psi(t)\rangle = e^{-iHt/\hbar}|\psi(0)\rangle$。
$H$ が[[数学/量子計算のための数学/エルミート行列|エルミート]]なので
$e^{-iHt/\hbar}$ は[[数学/量子計算のための数学/ユニタリ行列|ユニタリ]]になり、
確率が保存される。

[[量子シミュレーション/Hamiltonian-Simulation|量子シミュレーション]]は
この時間発展を量子回路で実装する問題。

## 数値解法

解析解が無いのが普通なので、[[数学/数値計算/方程式の数値解法|数値的に]]解く。
オイラー法、Runge-Kutta 法が基本。
[[量子シミュレーション/Trotter分解|Trotter 分解]]も、
指数関数の分割という意味で同じ系譜にある。
