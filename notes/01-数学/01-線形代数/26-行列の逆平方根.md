# 行列の逆平方根

$$A^{-1/2} = \bigl(A^{1/2}\bigr)^{-1} = Q \Lambda^{-1/2} Q^\top$$

[[数学/線形代数/固有値分解|固有値分解]]の対角成分を $1/\sqrt{\lambda_i}$ に置き換えるだけ。
$A$ は[[数学/線形代数/正定値行列|正定値]]（固有値がすべて正）である必要がある。

## 白色化

これを掛けると、共分散が単位行列になる。

$$x \sim \mathcal{N}(\mu, \Sigma) \;\Longrightarrow\; \Sigma^{-1/2}(x - \mu) \sim \mathcal{N}(0, I)$$

**歪んだ楕円分布を、真ん丸な標準正規に戻す**操作。
これを白色化 (whitening) と呼ぶ。

## なぜ嬉しいのか

球状に戻すと、**距離の意味が方向によらなくなる**。

| 場面 | 白色化する理由 |
| --- | --- |
| [[数学/最適化のための数学/Mahalanobis距離\|Mahalanobis 距離]] | $\sqrt{(x-\mu)^\top\Sigma^{-1}(x-\mu)} = \|\Sigma^{-1/2}(x-\mu)\|$ |
| [[最適化/進化計算/CMA-ES/ステップサイズ適応\|CMA-ES]] | 進化パスの長さを分布の形に依らず測る |
| 機械学習の前処理 | 特徴量のスケール差を消す |

## 数値的な注意

固有値が 0 に近いと $1/\sqrt{\lambda}$ が発散する。
[[数学/数値計算/条件数|条件数]]が大きい行列では
小さい固有値に切り捨てを入れる（正則化）のが実務的な対処。
