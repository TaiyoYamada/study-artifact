# 正定値行列

$$x^\top A x > 0 \qquad \text{for all } x \ne 0$$

（$\ge 0$ なら**半正定値**。）通常は[[数学/線形代数/対称行列|対称]]な行列について言う。

## 同値な条件

- すべての固有値が正
- すべての首座小行列式が正（Sylvester の判定法）
- $A = L L^\top$ とコレスキー分解できる

実装では**コレスキー分解を試みて成功するか**で判定するのが最も速く安定。

## 何を意味するか

$x^\top A x$ は[[数学/線形代数/二次形式|二次形式]]。
正定値ならこれは上に開いた「お椀」の形になる。

| 場面 | 正定値であることの意味 |
| --- | --- |
| [[数学/微分積分/ヘッセ行列\|ヘッセ行列]] | その点で狭義凸。極小点である |
| [[数学/線形代数/共分散行列\|共分散行列]] | どの方向にも分散がある（退化していない） |
| [[最適化/勾配に基づく最適化/Newton法\|Newton 法]] | $-H^{-1}\nabla f$ が下る方向になる |
| [[最適化/数理最適化/二次計画法\|二次計画]] | 問題が凸で、多項式時間で解ける |

## 半正定値との違い

半正定値（固有値に 0 を含む）は、ある方向に**平坦**であることを意味する。
共分散行列なら、その方向に分散が無い＝データが低次元の部分空間に載っている。
[[最適化/進化計算/CMA-ES|CMA-ES]] で共分散行列が半正定値に近づくと、
その方向の探索が止まってしまうため、数値的な下限を設ける実装がある。
