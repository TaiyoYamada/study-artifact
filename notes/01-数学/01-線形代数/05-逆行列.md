# 逆行列

$$A A^{-1} = A^{-1} A = I$$

$A$ が表す[[数学/線形代数/線形写像|線形写像]]の**逆写像**にあたる行列。

## 存在条件

正方行列 $A$ について、次はすべて同値。

- $A^{-1}$ が存在する
- $\det A \ne 0$（[[数学/線形代数/行列式|行列式]]が 0 でない）
- [[数学/線形代数/ランク|ランク]]が $n$（フルランク）
- 列ベクトルが[[数学/線形代数/線形独立|線形独立]]
- $Ax = 0 \Rightarrow x = 0$
- 固有値に 0 が無い

どれか 1 つ確かめれば残りも言える。

## 計算してはいけない

$Ax = b$ を解くとき、**$A^{-1}$ を求めて掛けるのは悪手**。

- 計算量が多い（$\mathcal{O}(n^3)$ だが定数が大きい）
- 数値誤差が大きい

LU 分解して前進・後退代入する方が速く、精度も良い。
NumPy でも `np.linalg.solve(A, b)` を使い、
`inv(A) @ b` は避けるのが定石。

## 悪条件

$\det A$ が 0 に近いと、$A^{-1}$ は存在しても
**数値的に信用できない**。この度合いを測るのが
[[数学/数値計算/条件数|条件数]]で、
$\kappa(A) = \|A\| \|A^{-1}\|$ が大きいほど、
入力の小さな誤差が解に拡大される。
