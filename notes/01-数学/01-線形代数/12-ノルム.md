# ノルム

**ベクトルの「長さ」を測る関数。** $\|x\|$ と書く。

## 満たすべき条件

1. $\|x\| \ge 0$、$\|x\| = 0 \iff x = 0$
2. $\|cx\| = |c| \|x\|$
3. $\|x + y\| \le \|x\| + \|y\|$（三角不等式）

これを満たせば何でもノルム。**長さの測り方は 1 つではない。**

## 代表的なノルム

$$\|x\|_p = \left( \sum_i |x_i|^p \right)^{1/p}$$

| ノルム | 式 | 性質 |
| --- | --- | --- |
| $L_1$ | $\sum \|x_i\|$ | 疎な解を導く（Lasso） |
| $L_2$ | $\sqrt{\sum x_i^2}$ | 内積から誘導される。回転不変 |
| $L_\infty$ | $\max \|x_i\|$ | 最大成分だけを見る |

## 選び方で結果が変わる

正則化に $L_1$ を使うと**係数が 0 になる**（変数選択が起きる）。
$L_2$ では 0 に近づくが 0 にはならない。
これは $L_1$ 球が座標軸上に尖った頂点を持つためで、
最適解がそこに当たりやすい。

[[人工知能/深層学習/正則化|深層学習の正則化]]で $L_1$ と $L_2$ を
使い分ける理由がここにある。

## 行列のノルム

行列にもノルムがある。作用素ノルム（スペクトルノルム）は

$$\|A\|_2 = \max_{x \ne 0} \frac{\|Ax\|}{\|x\|} = \sigma_{\max}(A)$$

最大[[数学/線形代数/特異値分解|特異値]]に一致する。
[[数学/数値計算/条件数|条件数]] $\kappa = \sigma_{\max}/\sigma_{\min}$ の定義に使われる。
