# 座標変換

**同じベクトルを、別の[[数学/線形代数/基底|基底]]で表し直すこと。**

基底 $B = (b_1, \dots, b_n)$ での座標を $[x]_B$ と書くと

$$x = B\,[x]_B \qquad \Longleftrightarrow \qquad [x]_B = B^{-1} x$$

## 行列も変換される

$A$ が表す[[数学/線形代数/線形写像|線形写像]]を新しい基底で書くと

$$[A]_B = B^{-1} A B$$

これを**相似変換**と呼ぶ。[[数学/線形代数/対角化|対角化]] $A = P\Lambda P^{-1}$ は
「固有ベクトルを基底に取れば対角になる」という座標変換の主張。

## 何が変わり、何が変わらないか

| 変わる | 変わらない（相似不変量） |
| --- | --- |
| 成分の値 | 固有値 |
| 見た目の複雑さ | [[数学/線形代数/行列式\|行列式]]、トレース、[[数学/線形代数/ランク\|ランク]] |

**本質的な性質は基底に依存しない。**
だから「良い基底を選ぶ」ことは、対象を変えずに見通しを良くする操作になる。

## 直交基底なら簡単

$B$ が[[数学/線形代数/直交行列|直交行列]]なら $B^{-1} = B^\top$ なので、
逆行列の計算が不要。数値的にも安定。
[[最適化/進化計算/CMA-ES/固有値分解と白色化|CMA-ES の白色化]]も、
直交行列と対角行列の組み合わせで座標変換している。
