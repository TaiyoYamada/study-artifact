# 行列の平方根

$$S^2 = A$$

を満たす $S$。$A$ が[[数学/線形代数/正定値行列|半正定値対称]]なら、
**半正定値対称な平方根が一意に存在する**。

## 求め方

[[数学/線形代数/固有値分解|固有値分解]]して、対角成分の平方根を取る。

$$A = Q\Lambda Q^\top \;\Longrightarrow\; A^{1/2} = Q \Lambda^{1/2} Q^\top$$

固有値が非負であることが必要で、だから半正定値性が前提になる。

## コレスキー分解との違い

$A = LL^\top$（$L$ は下三角）も「平方根」と呼ばれることがあるが、
$L$ は対称ではないので $L^2 \ne A$。

| | 対称平方根 $A^{1/2}$ | コレスキー $L$ |
| --- | --- | --- |
| 形 | 対称 | 下三角 |
| 計算量 | $\mathcal{O}(n^3)$（固有値分解） | $\mathcal{O}(n^3/3)$、定数が小さい |
| 用途 | 理論、白色化 | 標本生成、正定値判定 |

**多変量正規分布から標本を引く**用途ならコレスキーで十分で、速い。
$x = \mu + Lz$（$z \sim \mathcal{N}(0,I)$）とすれば $\mathrm{Cov}(x) = LL^\top = \Sigma$。

## どこで使うか

- [[数学/確率/多変量正規分布|多変量正規分布]]からの標本生成
- [[最適化/進化計算/CMA-ES/固有値分解と白色化|CMA-ES]] の $C^{1/2} = BD$
