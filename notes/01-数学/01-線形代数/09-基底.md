# 基底

**空間を張り、かつ線形独立なベクトルの組。**

$$\text{任意の } x \text{ が } x = \sum_i c_i b_i \text{ と一意に書ける}$$

「張る」は全部作れること、「[[数学/線形代数/線形独立|線形独立]]」は
無駄がないこと。両方あって初めて**表現が一意**になる。

## 基底は 1 つではない

同じ空間に無数の基底がある。標準基底 $e_1, \dots, e_n$ は
そのひとつにすぎない。

**どの基底を選ぶかで問題の見え方が変わる**、というのが線形代数の実用的な要点。

| 選ぶ基底 | 得られること |
| --- | --- |
| [[数学/線形代数/固有値・固有ベクトル\|固有ベクトル]] | 行列が[[数学/線形代数/対角化\|対角]]になる |
| [[数学/線形代数/共分散行列\|共分散行列]]の固有ベクトル | 主成分分析。分散が最大の方向 |
| フーリエ基底 | 周波数成分に分解される |

[[最適化/進化計算/CMA-ES/固有値分解と白色化|CMA-ES が固有値分解する]]のも、
探索に都合の良い基底へ移るため。

## 次元

基底の個数はどの基底を選んでも同じで、これを**次元**と呼ぶ。
$n$ 量子ビットの状態空間は $2^n$ 次元。
