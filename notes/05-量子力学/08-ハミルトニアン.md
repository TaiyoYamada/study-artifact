# ハミルトニアン

**系の全エネルギーを表す[[数学/量子計算のための数学/エルミート行列|エルミート演算子]]。** $\hat{H}$。

古典力学のハミルトニアン（運動エネルギー + ポテンシャル）を
演算子に置き換えたもの。

$$\hat{H} = \frac{\hat{p}^2}{2m} + V(\hat{x})$$

## 2 つの役割

**1. エネルギーの観測量** — 固有値がエネルギー準位。

$$\hat{H}|\psi_n\rangle = E_n |\psi_n\rangle$$

最小固有値が**基底エネルギー**。

**2. 時間発展の生成子** — [[量子力学/シュレディンガー方程式|シュレディンガー方程式]]により

$$U(t) = e^{-i\hat{H}t/\hbar}$$

$\hat H$ がエルミートだから $U$ が
[[数学/量子計算のための数学/ユニタリ行列|ユニタリ]]になる。
**エネルギーが時間発展を決める**という構造。

## 量子計算での位置づけ

| 場面 | ハミルトニアン |
| --- | --- |
| [[量子化学/分子ハミルトニアン\|量子化学]] | 電子と核の相互作用 |
| [[最適化/QUBO最適化/イジングモデル\|最適化]] | イジング模型。基底状態が最適解 |
| [[最適化/量子最適化/量子アニーリング\|量子アニーリング]] | 初期 $H$ から問題 $H$ へ連続変形 |
| [[量子シミュレーション/Hamiltonian-Simulation\|量子シミュレーション]] | $e^{-iHt}$ を回路で実装 |

**「基底状態を求める」という 1 つの問題**に、
量子化学も組合せ最適化も帰着する。
これが量子計算の応用が集中している理由。

## パウリ分解

任意のハミルトニアンはパウリ演算子のテンソル積の和に書ける。

$$H = \sum_k c_k \, P_k, \qquad P_k \in \{I, X, Y, Z\}^{\otimes n}$$

[[最適化/量子最適化/VQEによる最適化|VQE]] では各項を別々に測定するため、
**項数がそのまま測定コスト**になる。
分子ハミルトニアンでは項数が $\mathcal{O}(n^4)$ に達し、
これが実用化の障壁のひとつ。
