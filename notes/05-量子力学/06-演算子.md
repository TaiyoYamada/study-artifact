# 演算子

状態に作用する線形写像。詳しい代数的性質は
[[数学/量子計算のための数学/演算子|数学側のノート]]にまとめてある。
ここでは物理的な意味を書く。

## 観測量はエルミート

測定値が実数でなければならないので、
観測量は[[数学/量子計算のための数学/エルミート行列|エルミート演算子]]で表される。

| 物理量 | 演算子 |
| --- | --- |
| 位置 | $\hat{x}$（掛け算） |
| 運動量 | $\hat{p} = -i\hbar\,\partial/\partial x$ |
| エネルギー | [[量子力学/ハミルトニアン\|ハミルトニアン]] $\hat{H}$ |
| [[量子力学/スピン\|スピン]] | パウリ演算子 $\sigma_x, \sigma_y, \sigma_z$ |

## 期待値

$$\langle A \rangle = \langle\psi|A|\psi\rangle$$

同じ状態を多数用意して測り、平均した値。
1 回の測定では固有値のどれかが出るだけで、
期待値そのものは直接観測できない。

## 交換しないことの意味

$[A,B] = AB - BA \ne 0$ なら、$A$ と $B$ は
**同時に確定した値を持てない**。共通の固有状態が無いため。

位置と運動量 $[\hat x, \hat p] = i\hbar$ から
不確定性関係 $\Delta x \Delta p \ge \hbar/2$ が出る。

これは測定装置の限界ではなく、
**状態がそもそもそういう性質を持たない**という主張。
