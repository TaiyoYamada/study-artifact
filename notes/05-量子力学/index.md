# 量子力学

**原子や光のスケールで成り立つ物理法則。**
量子計算の土台であり、その規則をそのまま計算資源として使う。

## 古典物理と何が違うか

| | 古典 | 量子 |
| --- | --- | --- |
| 状態 | 位置と速度が確定 | [[量子力学/量子状態\|状態ベクトル]]。[[量子力学/重ね合わせ\|重ね合わせ]]が可能 |
| 観測 | 状態を変えない | [[量子力学/測定\|測定が状態を変える]] |
| 予測 | 決定論的 | 確率的（[[数学/量子計算のための数学/確率振幅\|Born 則]]） |
| 合成 | 各部分の状態の組 | [[量子力学/量子もつれ\|分離できない状態]]が存在 |

## 数学的な骨格

量子力学の内容は、ほぼ**複素[[数学/量子計算のための数学/内積空間|ヒルベルト空間]]の
線形代数**として書ける。

- 状態 = 単位ベクトル
- 観測量 = [[数学/量子計算のための数学/エルミート行列|エルミート演算子]]
- 時間発展 = [[数学/量子計算のための数学/ユニタリ行列|ユニタリ変換]]
- 測定 = [[数学/線形代数/射影|射影]]と確率

物理的な解釈をひとまず脇に置いても、
**計算の規則としては完全に定義されている**。
量子計算を学ぶ上では、まずこの規則を受け入れて使うのが早い。
