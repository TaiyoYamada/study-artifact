# 固有値・固有状態

$$\hat{A}|a\rangle = a|a\rangle$$

**固有状態にある系を測ると、必ず対応する固有値が出る。**
確率が 1 に集中する唯一の場合。

## 測定の理論そのもの

[[量子力学/測定|測定]]の規則は固有値問題として書かれている。

- 得られる値の候補 = 固有値の集合（**スペクトル**）
- 測定後の状態 = 対応する固有状態
- 確率 = 固有状態への[[数学/線形代数/射影|射影]]の大きさ

エルミート性により固有値は実数、
固有状態は[[数学/線形代数/直交|直交]]基底をなす。
**異なる測定結果に対応する状態は完全に区別できる**、
という性質がここから出る。

## エネルギー固有状態

[[量子力学/ハミルトニアン|ハミルトニアン]]の固有状態は**定常状態**。
時間が経っても位相しか変わらない。

$$|\psi(t)\rangle = e^{-iE t/\hbar}|\psi(0)\rangle$$

大域位相なので観測可能な性質が変化しない。
最小固有値の状態が**基底状態**で、
[[最適化/量子最適化/VQEによる最適化|VQE]] や
[[量子化学/量子化学の基礎|量子化学]]が求めているもの。

## 縮退

同じ固有値に複数の固有状態が対応する場合。
測定してもどの状態かは決まらず、
その固有空間への射影になる。
